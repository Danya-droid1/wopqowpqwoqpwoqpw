# digital-signal-encoding

Digital Comms Module — учебный проект на Python для моделирования многоступенчатой подготовки данных к передаче по каналам связи.

Реализует 4 этапа:

- Формирование сообщения в кастомной 8-битной кодировке (кириллица/латиница/цифры)

- Физическое кодирование: NRZ-L, NRZ-I, Manchester, AMI с расчётом спектральных параметров

- Логическое кодирование методом 4B/5B (избыточность 25%)

- Скремблирование на основе LFSR и спектральный анализ через БПФ

Каждый скрипт работает автономно: принимает входные данные, выводит результат в консоль и строит временные/частотные диаграммы (matplotlib).

Требования: Python 3.8+, numpy, matplotlib

Запуск: pip install -r requirements.txt && python stage_*.py

Проект разработан в рамках курсовой работы по дисциплине «Цифровая связь». Код предоставлен в учебных целях (лицензия MIT).
